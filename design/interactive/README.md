# InputSwitch 可交互设计稿

直接用浏览器打开 [index.html](index.html)，不需要安装依赖或启动 InputSwitch。HTML、CSS、JavaScript 与品牌图标均在仓库内，支持离线使用。

## 设计范围

本次是完整的界面与交互原型，未改动生产面板、Rust 后端或版本号。演示数据会在页面顶栏标明，不切换真实屏幕、不发送文件、不修改系统设置。选择本地文件只使用文件名与大小，不读取文件内容。

采用用户确认的一体化壳体：标题栏、导航和状态栏共享连续底色，内容区域直接衔接窗口；没有外围画布、悬浮窗口或重复设计工具条。“设计预览”工具位于右上角，需要时展开。

- 工作台：单屏切换与多屏共享同等呈现，切换视图不更改每台设备的布局。画面归属、键鼠归属、主切换按钮和三项维护操作常驻。
- 设备与布局：配对输入、随机配对码、等待确认、设备选择、点击摆位、拖动、方向键移动和撤销。共用一块屏与四向邻接可以并存。
- 文件传输：文件及文件夹选择、拖放、无需选文件即可体验的演示传输、进度、暂停、继续、取消、失败重试、筛选与分页。
- 设置：键鼠、剪贴板、光标速度、快捷键录制、开机自启、自动恢复、崩溃守护、副机模式、浅深色、减少动态效果和更新反馈。
- 反馈：成功提示、等待状态、设备离线、未配对、切换失败、无输入源。切换成功只在模拟确认后更新；紧急断开优先于迟到的键鼠交接。

## 体验方式

1. 点顶部主按钮，观察“发送请求 → 等待确认 → 画面与键鼠归属改变”。
2. 切到“多屏共享”，点“体验跨屏”；再到“设备与布局”选 ThinkPad，点方向、拖动或使用方向键，随后撤销。
3. 在“文件传输”点“体验一次传输”，尝试暂停、继续、取消和重试。
4. 在“设置”修改快捷键、开关或外观。偏好只存在浏览器的原型存储中。
5. 点右上角“设计预览”，用“演示状态”切到离线、未配对或失败。用“窗口”检查 1080 × 720、820 × 680 和 600 × 520。
6. “重置”恢复默认演示；Ctrl + Alt + Esc 结束当前模拟键鼠共享。

窗口内以分页和分区组织内容。默认铺满预览窗口；在 1080 × 720、原有 820 像素宽窗口和 600 × 520 最小窗口下验证。更窄的预览侧栏使用图标导航，窄于桌面最小尺寸时仍有浏览器适配。

可选 URL 参数：?scene=multi、?page=devices、?page=transfers、?page=settings、?state=offline、?theme=dark。?embed=1 隐藏“设计预览”入口，以浏览器视口直接模拟应用窗口。参数可以组合。

## 验证

verify.cjs 使用 Playwright 和 Chromium/Windows Edge，验证用户操作、异步反馈、焦点恢复以及各尺寸下的内容边界。测试不会访问生产 API。

    # 已安装 Playwright 时直接运行；也可通过此环境变量指定现有安装位置。
    $env:INPUTSWITCH_PLAYWRIGHT = '你的 Playwright 包目录'
    node design/interactive/verify.cjs --capture
    node tools/panelcheck.js assets/panel

截图与验证报告写入 .impeccable/review/（本地验收资产，不随仓库发布）。无 --capture 时只运行验证。

设计系统见仓库根目录 DESIGN.md；设计稿保留了现有主动作、维护入口、真实输入口验证和每设备布局的产品约束，正式接入时仍应以现有后端回执为状态来源。
