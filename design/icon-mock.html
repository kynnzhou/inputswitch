InputSwitch · 图标设计稿

品牌记号就做 is 两个字母。色板沿用现有的深蓝 #232A38 + 薄荷绿 #4EE0B5，不引新颜色。 下面是两条路线，都按 1024 出图，并排看 1024 / 256 / 128 / 64 / 32 / 16 六级缩放。

先说明：起点试过六个变体 —— i 的竖笔弯成 s、开关轨道里放 is、s 收成箭头、is 加边界竖线 —— 1024 下都还能看，但缩到 64px 以下全部糊成一团或者读成别的字母（“Ls”“oS”“Fs”）。 真正站得住的只有下面两条。

1纯字标推荐

i 的竖笔 + 圆点，s 用两段反向圆弧咬合。笔画等宽（86/1024）、端点全圆， 和面板里那套 10px 圆角按钮是同一套语言。字面宽 470，四周留白 ≥ 280， 在系统图标网格里不会顶着边。

2方框徽章备选

同样的 is，外面加一圈圆角方框。方框把字标收成一个整体，也让"这软件是个框在管着屏幕"这件事有一点暗示。 但 32px 下框线和笔画一样粗，会挤成一块；实际会做一版"小尺寸去掉方框"的规则。

菜单栏与托盘

macOS 菜单栏用模板图（只有 alpha，系统按明暗自动反色），22×22（@2x 为 44）。 那个尺寸放不下两个字母还认得出，所以取笔画更简的 i：一个圆点加一根竖笔， 和图标里 i 的比例完全一致。Windows 托盘是彩色小图，直接缩字标的 16px 版本。

我推荐 1（纯字标）

原因：小尺寸下是唯一还能读出字的一个。图标最终活在 32px 和 16px 上， 而“方框 + is”在 32px 时框线和笔画会挤在一起。

落地范围： assets/AppIcon-1024.png、AppIcon.icns（macOS 装包）、 AppIcon.ico（16–256 九个尺寸，Windows exe 内嵌 + 资源管理器）、 menubar.png / menubar@2x.png（菜单栏模板图）。 图标由脚本按同一份矢量几何生成，以后改色只改一处。
